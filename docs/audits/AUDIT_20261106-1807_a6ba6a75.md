## Rich Hickey pass

- `tile-contract/TileContract.kt` (50): the best-shaped decision in the repo. One module owns the wire
  format, pure data class + two pure functions, no Android and no GMS, so both ends can test it on a JVM.
  Positional 8-field encode with a version int, guarded by `f.size != 8` + `toIntOrNull`/`toBooleanStrictOrNull`
  — no exceptions, `null` for every malformed input. The `SEP = "\u001F"` comment claims it "never appears in
  podcast metadata": that holds for the only input source, since 0x1F is not a legal XML 1.0 character, so a feed
  cannot smuggle it in. Residual, honest: if a separator ever did appear in a title, `decode` returns null →
  frame dropped + logged (:24) → the tile freezes on the last good frame, which is M41 with a different trigger.

  for in `Migrations.kt`** — extract the decision, leave the Android-coupled shell thin. Copy it.
