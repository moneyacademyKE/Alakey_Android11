Correct shape. `ATTR_AUDIO_PATH` swapping `audioUrl` to the local path is slightly sneaky (one field, two meanings depending on facts) but it makes `deleteDownload`'s `audioUrl.startsWith("/")` check correct — verified, not a bug.

Borderline: it adds an indirection layer over five repositories that Hilt could inject directly, but it also owns the genuinely compositional `library/queue/inbox` flows.
