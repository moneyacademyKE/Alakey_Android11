## Rich Hickey pass

- **PureLogic.kt (65):** the pure-function intent is right, but three things are complected. Date *parsing* (failure-prone, format-dependent) is embedded in functions that should only *compare* values; the `0L` sentinel converts "unknown" into a value that participates in ordering (M56); and two of the three policy branches are unreachable (L54). Simplest shape: `parseDate: String -> Long?`, callers filter nulls, delete the policy switch until a setting exists — less code than today, same behaviour.
- **InformationModel.kt (50):** honest data-in/data-out. The `base.copy(...)` then five `var` assignments (:42-48) exists only because volatile state lives outside the constructor — that separation is the entity's stated design and is worth keeping; the cost lands in the UI, which memoizes on identity while rendering state (M55).
- **NetworkLogic.kt (30):** half dead (`extractProxyContent`, L43), and the live half allocates a `Gson()` per call and collapses "malformed" into "no results" — the same conflation as M19/L23, cross-referenced, not re-filed.
- **HeadsetResumeLogic.kt (7):** the template the rest of the layer should copy — one predicate, no state, pinned on all three branches.
- **The complection to name:** this layer is "pure" only where it is *wired* (HeadsetResumeLogic). Where purity would have paid (M54's range, M56's sentinel) values are compared across units and meanings nothing states, and the one test file touching the layer (`AppReducerTest`) asserts a `Set` for "All" — deliberately order-blind, because every fixture date parses to 0.
