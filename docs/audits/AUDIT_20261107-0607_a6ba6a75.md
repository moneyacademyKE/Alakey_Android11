## Rich Hickey pass
- **PlaybackClient.kt (432)** — cleanup() hand-manages four Job fields to do what one `scope.cancel()` subsumes. Hand-rolled cancellation IS the incidental complexity here: structured concurrency already solves it, and the hand-rolled version is provably incomplete (reconcileJob, :96 and :176 all escape it). The name promises a lifecycle boundary; the body does partial bookkeeping. One line makes the name true.
- **repl/ReplReceiver.kt (37)** — a class that should not exist. It is a second implementation of `assert-fact` in a different source set: unregistered, undocumented, unreachable. Delete it and fold nothing, because the registered debug receiver already has the command. The complection to name is duplication across source sets — two REPL surfaces, one live and one ghost, and M32 already proved the docs describe a third.
- **Cancellation surface, tree-wide** — exactly two self-made scopes exist in main source (PlaybackClient:66, ReplReceiver:19) and neither is ever cancelled; everything else is framework-scoped and correct. Small, closed, fixable — not systemic.
